# Frontend (Next.js)

Public booking site, admin dashboard, shipper board (`/ship`), and Messenger chat simulator (`/admin/terms`).

## Setup

```bash
cp .env.local.example .env.local
npm install
npm run dev
```

Dev server: [http://localhost:3001](http://localhost:3001).

## Scripts

```bash
npm run dev
npm run build
npm start
```
